# Threat model

Inputs are untrusted. Flat scalar records, strict UTF-8, duplicate-key rejection, finite numbers, 8 MiB dataset limit, 50,000 rows, 256 fields; CLI contracts bounded to 64 KiB. File identity and metadata checks, no-follow, nonblocking read-only opens, traversal denial. Trusted root and parents required; hostile concurrent filesystem mutation is not fully isolated. Dashboard binds loopback on CLI startup, validates host/origin/token and content type, caps request body at 24 MiB and individual datasets/contracts, limits concurrent analyses, uses CSP, no-store and textContent rendering. Not authentication; never expose via proxy. Local malicious processes, OS compromise, resource exhaustion within bounded inputs and browser extensions are outside isolation guarantees. Raw records, field names, hashes and aggregates may be sensitive. Heuristics and fingerprints do not guarantee anonymization or leakage prevention. No external upload or automated remediation. Browser and adversarial tests run in CI; final acceptance pending exact-head evidence.
